# Adversarial-Margin-Learning
A PyTorch implementation for our paper "Label-Aware Adversarial Margin Learning via Soft Prompting for Robust short Text Classification".

## Requirement

- Python = 3.9
- torch = 2.1.0
- numpy = 1.23.5
- transformers = 4.34.1
Note: This requirement pertains to the author's experimental environment. The same version may not be necessary for actual use.
## Preparation

### Clone

```bash
git clone https://github.com/sushun176/Adversarial-Margin-Learning.git
```

### Create an anaconda environment:

```bash
conda create -n aml python=3.9
conda activate aml
pip install -r requirements.txt
```

## Usage

```sh
python main.py
```
